
# 📘 Biblioteca Digital

## 📄 Descripción del Proyecto

**Biblioteca Digital** es una aplicación web diseñada para la gestión y visualización de libros. Permite registrar nuevos títulos, consultar información detallada, y mantener organizada una colección de libros mediante una interfaz amigable para el usuario.

### 🎯 Objetivo
Facilitar el almacenamiento, organización y consulta de libros en línea mediante un sistema accesible desde cualquier navegador.
